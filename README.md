# nixos-config

NixOS and Home Manager configuration for three machines, as a single flake on NixOS 26.05.

| Host | Flake output | What it is |
|---|---|---|
| desktop | `nix-desktop` | Hyprland (UWSM, SDDM), NVIDIA open driver, Steam/gaming, mpd + rmpc |
| laptop | `nix-laptop` | GNOME (GDM), NVIDIA proprietary driver, WireGuard client for the home server |
| hs | `nix-hs` | Headless home server: SSH, WireGuard, DynDNS, fail2ban, 4 TB USB disk at `/srv/data` |

## Layout

```
flake.nix                     inputs, mkHost (with Home Manager) and mkServer (without)
assets/                       wallpaper and wlogout icons
hosts/<host>/
  configuration.nix           imports + anything that only applies to this machine
  hardware-configuration.nix  generated by nixos-generate-config
  home.nix                    Home Manager entry point (desktop, laptop)
  secrets.nix                 which agenix secrets this host gets (laptop, hs)
modules/nixos/
  base.nix                    every host: nix settings, bootloader, locale, agenix
  workstation/                desktop + laptop: audio, fonts, printing, bluetooth, LanguageTool, user ado
  desktops/                   gnome.nix, hyprland.nix
  hardware/nvidia.nix         open driver by default, a host can set open = false
  gaming.nix                  Steam, Proton-GE, gamescope, Lutris, Prism Launcher
  server/                     SSH, firewall, fail2ban, WireGuard, DynDNS, users, time, logging
modules/home/
  default.nix                 shared by both graphical hosts: CLI, tmux, dev tools, LibreWolf, Obsidian, apps
  theme.nix                   colors and font, available to every home module as `theme`
  desktops/gnome.nix          dconf settings
  desktops/hyprland/          Hyprland, waybar, wofi, hyprlock, hyprpaper, swaync, wlogout, GTK
  music/                      mpd + rmpc (YouTube search via rmpc-discover)
```

Each host chooses its own modules: `base.nix`, then `workstation` or `server`, then a
desktop and hardware. There is no automatic wiring beyond that.

### Module arguments

Besides the usual `pkgs`, `lib`, `config`, modules can take these as arguments:

| Argument | Comes from | Available in |
|---|---|---|
| `agenix`, `mysecrets`, `firefox-addons`, … | flake inputs (`specialArgs`) | NixOS and Home Manager modules |
| `assets` | `./assets` | desktop and laptop (not the server) |
| `theme` | `modules/home/theme.nix` | Home Manager modules |
| `lan` | `modules/nixos/server/lan.nix` | server modules; the only place for LAN/VPN subnets |
| `osConfig` | Home Manager | Home Manager modules, to read the host's NixOS config |

## Everyday use

`$FLAKE` points to `~/nixos-config`. The shell aliases live in `modules/home/cli.nix`.

```sh
nrs                        # rebuild and switch this machine
nrt                        # rebuild and test this machine (no boot entry)
hrs / hrt                  # same for the server, deployed over SSH to host "hs"
nix flake update           # update all inputs, then nrs
nix flake update mysecrets # pick up new commits in the secrets repo
treefmt                    # format every .nix file with nixfmt
```

`hrs`/`hrt` use the SSH alias `hs` (LAN address). From outside the LAN, connect the
WireGuard profile first; the alias `hs-vpn` reaches the server through the tunnel.

## Secrets

Secrets are encrypted with [agenix](https://github.com/ryantm/agenix) and live in a separate
private repo, `~/nix-secrets`, which the flake reads as the `mysecrets` input. That repo holds:

- the `*.age` files
- `keys.nix`: public SSH and WireGuard keys, imported by the server and laptop modules
- the agenix rules file that says which keys can decrypt which secret

Every host decrypts with its own key at `/var/lib/agenix/key` (set once in `base.nix`).

| Secret | Used by | For |
|---|---|---|
| `passwort-ado.age` | desktop, laptop | password hash for `ado` (`users.mutableUsers = false`) |
| `wg-laptop.env.age` | laptop | WireGuard private key for the NetworkManager profile |
| `wg-hs.age` | hs | WireGuard server private key |
| `cloudflare-token.age` | hs | API token for DynDNS |

Editing or adding a secret:

1. In `~/nix-secrets`: `vage <name>.age` (agenix with the `~/.ssh/id_ed25519_agenix` key).
   For a new secret, add it to the rules file first.
2. Commit in `~/nix-secrets`. The input is `git+file`, so uncommitted files are invisible
   to the build.
3. In `nixos-config`: `nix flake update mysecrets`, then reference the file in
   `hosts/<host>/secrets.nix` (or a module) and rebuild.

## Obsidian

`modules/home/obsidian.nix` sets up one vault, `~/Documents/vault`, on both graphical hosts.

- **Plugins** are pinned GitHub releases. To update one, change its `version` and replace
  each hash with the output of
  `nix store prefetch-file https://github.com/<owner>/<repo>/releases/download/<version>/<file>`.
- **LanguageTool** checks against the local server from `workstation/languagetool.nix`
  (socket-activated on `127.0.0.1:8081`), not api.languagetool.org. Its `data.json` is
  managed by Nix, so settings changed in the plugin's tab won't stick; set them in
  `obsidian.nix`.
- **Encrypted Git Sync** keeps its own, writable `data.json`. Its token and passphrase go
  to the system keyring: KWallet on the desktop (Obsidian runs with
  `--password-store=kwallet6`), GNOME Keyring on the laptop.
- `app.json`, `appearance.json` and the plugin lists are managed by Nix as well.

## Home server

- **SSH** on port 2222, keys only, user `nixhs`. The firewall allows it from the LAN and
  the VPN only; it is not open to the internet.
- **WireGuard** `wg0` on UDP 51820, subnet `10.77.0.0/24`. The server is `.1`, the phone
  `.2`, the laptop `.3`. Peers are listed in `modules/nixos/server/wireguard.nix`.
- **DynDNS** keeps a Cloudflare record pointed at the home connection (IPv4 and IPv6).
  It must stay unproxied, otherwise WireGuard can't connect.
- **fail2ban** bans after 3 failed SSH attempts for 1h, never for the LAN or VPN.
- **Firewall** is nftables. Everything not accepted is dropped, and the last rule logs
  drops with the prefix `fw-drop:` (`journalctl -k | grep fw-drop`).
- If the ISP changes the IPv6 prefix, update `modules/nixos/server/lan.nix`.

## Adding a host

1. Install NixOS, copy its `hardware-configuration.nix` to `hosts/<name>/`.
2. Write `hosts/<name>/configuration.nix`: import `base.nix` plus `workstation` or `server`,
   set `networking.hostName` and `system.stateVersion`.
3. For a graphical host, add `hosts/<name>/home.nix` (import `modules/home` and a desktop,
   set `home.stateVersion`).
4. Add it to `nixosConfigurations` in `flake.nix` with `mkHost` or `mkServer`.
5. Secrets: put the host's private key at `/var/lib/agenix/key`, add its public key to the
   rules in `~/nix-secrets`, run `agenix -r`, commit, `nix flake update mysecrets`.
6. On the new machine, clone this repo to `~/nixos-config` and the secrets repo to
   `~/nix-secrets` (the flake expects that path), then
   `sudo nixos-rebuild switch --flake .#<output-name>`.
